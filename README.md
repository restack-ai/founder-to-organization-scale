# Founder to Organization Scale — public deck

A presentation of the [founder-to-organization-scale](https://github.com/restack-ai/founder-to-organization-scale) operating manual, for startup audiences at every stage.

**Live:** https://restack-ai.github.io/founder-to-organization-scale/

- Navigate with ←/→, Space, or the thumbnail rail. `#N` in the URL jumps to slide N.
- Dark/light toggle top-right. Print → Save as PDF gives one page per slide.
- Chart data is editable in `window.QF_DECK_DATA` inside `index.html`.

Built with the [QuietFabric design system](https://github.com/restack-ai/quite-fabric-design-system) deck components (`deck.css`, `deck-stage.js`, `deck-charts.js`) and the Decision Atlas typography from `DESIGN.md`: IBM Plex Sans Condensed, Inter, and IBM Plex Mono. Content sources and citations live in the main branch (`bibliography.md`).
