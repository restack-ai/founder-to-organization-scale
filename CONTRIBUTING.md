# Contributing

This repo is intended to become an open operating manual.

Good contributions include:

- real-world decision-rights templates;
- case studies with sources;
- diagrams that clarify operating mechanisms;
- AI-agent governance patterns;
- metrics that help detect founder bottlenecks;
- examples of failed delegation and what fixed it.

## Contribution style

- Prefer practical templates over abstract claims.
- Cite sources when making factual claims.
- Mark opinionated patterns as opinionated.
- Avoid pretending that one framework works for every company.
